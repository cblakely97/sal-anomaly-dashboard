Project Overview

This dashboard presents tidal validation results from MPAS-Ocean simulations on the Sandy unstructured mesh, comparing two run configurations that differ in how the self-attraction and loading (SAL) feedback is computed. Sea-surface height at 1,555 GESLA v4 tide gauge locations is recorded every 6 minutes over a one-year analysis window (2017) and compared against quality-controlled observations. Tidal constituents are extracted via UTide harmonic analysis, and non-tidal residuals are computed by subtracting the tidal reconstruction from the raw time series.

Run Configurations

BP Anomaly (coupled)

SAL computed using the full bottom pressure anomaly (bpanomaly), including both the dynamic SSH signal and the depth-integrated baroclinic pressure contribution. This is the primary experimental configuration testing the impact of a more physically consistent SAL forcing.

Run label: bpanomaly

Atmospheric Tide Only (baseline)

SAL computed using only the atmospheric tide contribution (atm-tide-only), representing the standard MPAS-Ocean configuration. Used as the control simulation against which the BP anomaly run is evaluated.

Run label: atm-tide-only

Validation Approach

For each GESLA station within the model domain, we:

  1. Extract the 6-min model SSH time series from the nearest MPAS cell.
  2. Read the co-located GESLA v4 observations for the same period, applying quality flags (use=1, qc≤2).
  3. Fit tidal harmonics to both model and observations independently using UTide (OLS, nodal corrections).
  4. Reconstruct the tidal signal and subtract to obtain the non-tidal residual (NTR).
  5. Compute RMSE, correlation, and bias over the overlapping valid data window.

Stations are excluded from the map if major constituent amplitudes (M2, S2, K1, O1) exceed 10 m or if |MSL offset| > 5 m, which typically indicates a datum issue in the GESLA record.
